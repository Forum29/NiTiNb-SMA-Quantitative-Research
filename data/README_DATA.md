# Which CSV should I open?

If you are new to the project, open the files in this order:

1. **`sma_extracted_data.csv`** — the original 9-row source-derived dataset. Every row tells you exactly which paper, figure and page it came from.
2. **`sma_analysis_ready_data.csv`** — the same 9 observations plus the calculated recovery-fraction and residual-fraction columns.
3. **`paper2_literature_findings.csv`** — the second paper's findings. These are kept separate because that paper studies TiNi rather than Ni-Ti-Nb.
4. **`paper_usage_matrix.csv`** — one-page explanation of exactly how both papers are used.
5. **`data_dictionary.md`** — column-by-column explanation.

Do not treat any of these as original laboratory measurements. The primary numerical rows are digitised from the published figure in P1.
